# بصمتي المرنة

تطبيق مستقل لمعلمي وزارة التربية في الكويت وإدارييها، يحسب مواعيد بصمات **الحضور والتواجد والانصراف** ونوافذها الصحيحة وفق البصمة المرنة، وينبّه قبل كل بصمة بـ 30 ثانية.

> تطبيق مستقل للمساعدة، **غير تابع لوزارة التربية**. المرجع النهائي سجلك الرسمي والقسم الإداري في مدرستك.

- **النسخة على الويب:** https://www.almaateeq.com/apps/basma/
- **نسخة أندرويد:** https://github.com/taroot80-blip/basma-marna/releases/latest/download/basma.apk

## ما يفعله
- يحسب نافذة التواجد (الستون دقيقة التالية لساعتين من بصمة الحضور) ووقت الانصراف بحسب المرحلة.
- يلتقط وقت الحضور تلقائيًا حين تفتح تطبيق «وزارة التربية - الكويت» (أندرويد)، ويقرأ الوقت الدقيق من لقطة شاشة «الحضور والانصراف» على الهاتف دون إنترنت.
- ينبّه بمنبّه النظام قبل كل بصمة حتى والتطبيق مغلق.
- يحسب أرصدة الاستئذانات والإجازات، ويرشد عند نسيان بصمة.

## الخصوصية
لا يجمع التطبيق أي بيانات ولا يرسلها؛ كل شيء محفوظ في هاتفك. لا يطلب اسم مستخدم ولا كلمة مرور، ولا يقرأ محتوى تطبيق الوزارة، بل يعرف فقط وقت فتحه وإغلاقه.

## البناء
يبنيه GitHub Actions تلقائيًا عند كل رفع إلى `main`، وتُنشر أحدث نسخة APK في الإصدار `latest`.
